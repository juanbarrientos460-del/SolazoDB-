# Scripts SQL

Ejecutar los archivos en orden numérico desde DBeaver, sobre la base de datos PostgreSQL definida para el proyecto.

1. `01_schemas.sql`
2. `02_ddl_tablas.sql`
3. `03_constraints_indexes.sql`
4. `04_vistas.sql`
5. `05_vistas_materializadas.sql`
6. `06_funciones_ventana.sql`
7. `07_consultas_negocio.sql`
8. `08_validacion_datos.sql`

Los scripts son una plantilla inicial. Completar el DDL cuando el modelo y el diccionario estén aprobados. Documentar si un script puede ejecutarse más de una vez y cómo se actualizan las vistas materializadas.
