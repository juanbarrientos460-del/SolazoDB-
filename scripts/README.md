# Scripts de preparación y carga

Esta carpeta contendrá herramientas para:

1. Descargar o recibir los archivos de la fuente autorizada.
2. Inspeccionar estructura y calidad.
3. Transformar los datos según reglas documentadas.
4. Cargar los datos en PostgreSQL.
5. Registrar filas leídas, insertadas, rechazadas y errores.

Documentar versiones de dependencias y parámetros de ejecución. No incluir credenciales ni contraseñas.
