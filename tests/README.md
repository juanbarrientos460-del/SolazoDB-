# Pruebas y validaciones

Agregar pruebas para:
- Integridad de claves primarias y foráneas.
- Restricciones y dominios de valores.
- Nulos y duplicados.
- Consistencia de marcas temporales y unidades.
- Reconciliación de filas entre origen, transformación y destino.
- Conteo mínimo de 1.000.000 de lecturas.
- Resultados esperados de vistas, vistas materializadas y funciones de ventana.
